Survey templates

Swap in a ready-made set of dimensions, or save your current setup so you (or a teammate) can reuse it later.

Import CSV

Expects the same columns as Export CSV: Squad, Dimension, Health, Trend, Note, Template, Dimension Key. The first column must stay the Squad name; the rest can be renamed or reordered freely — matching falls back to the original column order if no header names are recognized. The Dimension Key column is what keeps rows matching correctly even after a dimension's name has been edited or translated; without it (older exports), matching falls back to the Dimension name text. The Template column is how a mismatched dimension set gets flagged below.
